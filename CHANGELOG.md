# Versions / Changelog

## 0.2.0

### Nouveautés

- **Projekt Mobile**, l'app Android : partage un texte, un lien, un TikTok (vidéo ou
  photos), des images ou un MP3 vers un projet, par le réseau local. Appairage par QR code,
  file d'attente quand le PC est éteint, thèmes et langue, mises à jour transmises par le PC.
- **Réception sur le PC** : bouton 📱, page « 📥 Reçu du téléphone », images et TikToks
  posés dans le moodboard, bouton pour autoriser Projekt dans le pare-feu.
- **Interface en anglais** (☰ → Langue).
- **Assistant** :
  - réponses plus fiables : il lit mieux les longues pages et se relit avant de répondre ;
  - réglages ⚙ de ce qu'il a le droit de faire ;
  - mémoire du projet 🧠 (résumé, décisions, préférences, idées écartées) ;
  - notes de discussion rangées dans « 💬 Discussions » ;
  - conversations enregistrées 🗂 ;
  - aide intégrée pour installer Ollama et télécharger le modèle.
- **Accueil au premier lancement** et **projet d'exemple** (☰ → Aide).
- **☰ → Aide** : Signaler un problème, vérification des mises à jour (désactivée par
  défaut), À propos.

### À savoir

- La base de données passe en version 9 au premier lancement ; une sauvegarde est faite
  juste avant.

### New

- **Projekt Mobile**, the Android app: share text, links, TikToks (videos or photos),
  images or MP3s into a project over your local network. QR code pairing, a queue while
  the PC is off, themes and language, updates delivered by the PC.
- **Receiving on the PC**: 📱 button, "📥 Received from phone" page, images and TikToks
  placed on the moodboard, a button to allow Projekt through the firewall.
- **English interface** (☰ → Language).
- **Assistant**:
  - more reliable answers: it reads long pages better and checks its answer before replying;
  - ⚙ settings for what it may do;
  - 🧠 project memory (summary, decisions, preferences, rejected ideas);
  - discussion notes filed under "💬 Discussions";
  - 🗂 saved conversations;
  - built-in help to install Ollama and download the model.
- **Welcome screen on first launch** and a **sample project** (☰ → Help).
- **☰ → Help**: Report a problem, update check (off by default), About.

### Good to know

- The database moves to version 9 on first launch; a backup is made right before.
